# Switch Implementation

This project involves the implementation of a network switch with the following key functionalities:

## MAC Address Learning and MAC Table Updates
- Implemented MAC address learning to dynamically update the MAC address table as devices are discovered on the network.
  
## VLAN Configuration and Management (802.1Q)
- Configured and managed VLANs (Virtual Local Area Networks) to segment network traffic, ensuring better performance and security.

## Spanning Tree Protocol (802.1d)
- Implemented Spanning Tree Protocol (STP) to prevent network loops and ensure efficient data flow within the network topology.
